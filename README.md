# IPTV 管理台

一个基于 Node.js 的自托管 IPTV 管理台，用于维护自己的组播频道、线路、台标和电子节目单。管理台生成 M3U 和 XMLTV，rtp2httpd 负责组播转发和 FCC 快速换台，播放器通过 rtp2httpd 收看。

## 频道与节目单

- **频道与线路** · 按名称或组播地址搜索频道，支持分组和排序。同一频道可配置多条 RTP／UDP 线路，例如高清和超高清。台标支持图片链接或本地上传。
- **FCC** · 可以设置默认 FCC 地址和协议，每条 RTP 线路可以继承、覆盖或关闭。
- **EPG** · 支持多个 XMLTV 源，可单独刷新或全部刷新。在频道编辑页按名称或 ID 搜索并关联节目单。默认每天北京时间 **00:40、06:40、13:40、18:40** 刷新，时间可在设置中修改。
- **界面** · 适配桌面和手机，支持日间、夜间和跟随系统。

每个 EPG 源保留最近一次成功刷新的缓存。合并后的节目单支持 gzip 压缩和 ETag，多个源使用相同频道 ID 时仍能正确匹配。

## 飞牛 fnOS

项目提供 [FNOS FPK 安装包](https://github.com/shwhy1998/IPTV/releases/latest)，需要 NAS 上已有 **Node.js v22 或更高版本**。管理台通过飞牛桌面入口打开，由统一网关验证 NAS 管理员身份。频道配置和 EPG 缓存保存在应用数据目录，升级沿用已有数据。

订阅端口默认是 **8787**，供局域网内的 rtp2httpd 和播放器只读访问。

| 接口 | 用途 |
| --- | --- |
| `/playlist.m3u` | 供 rtp2httpd 作为外部 M3U 拉取，保留多线路标签和 FCC 参数 |
| `/epg.xml` | 已关联频道的合并节目单，通常由 M3U 引用 |

## 发布与台标

应用代码、依赖或打包配置合入 `main` 后，GitHub Actions 自动构建 FPK。[Releases](https://github.com/shwhy1998/IPTV/releases) 提供安装包、SHA-256 校验文件和每版改动说明。

[`logo/`](./logo/) 单独维护公开台标。台标目录的更新不触发 FPK 构建。
